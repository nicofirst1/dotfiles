# AGENTS.md

This is a personal dotfiles repository managed with GNU Stow: shell config (zsh, XDG-based paths), scripts, launch agents, and app configs for a UNIX-like dev environment on macOS/Linux.

**This repository is public** (github.com/nicofirst1/dotfiles). Never commit or push secrets, API keys, tokens, private hostnames/IPs, or any other private data. Machine-specific or sensitive settings belong in `.machine.sh` (gitignored), not in tracked files.
